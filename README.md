# PayCycle (給料日サイクル型 資金管理ダッシュボード)

Next.js (App Router), Tailwind CSS, Recharts を利用した、給料日起点サイクルによる自由資金・将来残高可視化ダッシュボードアプリケーションです。

## 主な機能
- **サイドバーナビゲーション (3画面切り替え)**:
  - ① **ダッシュボード / 分析**: 自由費ヒーロー、先月からの繰越金入力、資金配分円グラフ、独立した食費トラック、当サイクル臨時出費リスト
  - ② **カレンダー / 収支管理**: 給料日基準のインタラクティブカレンダー、日別収支・食費の直接入力、日別累積残高シミュレーション
  - ③ **データ管理 / 設定**: 給与・給料日設定、固定費・引き落とし予定、貯金・投資計画、5大カテゴリカラー設定、JSON/CSVバックアップ＆復元、全データ初期化
- **選択月（サイクル）への完全連動フィルタリング**:
  - 表示対象の給料日サイクル（先月分・今月分・来月分）に連動して、自由費・円グラフ・食費・臨時出費がその月専用のデータに厳密にフィルタリング。
- **カレンダー直接入力データの自動分類 ＆ リアルタイム反映**:
  - カレンダー日付セルから入力された収支を「食費」「臨時出費」「臨時収入」へ自動分類し、円グラフや自由に使えるお金へ即座に反映。
- **「先月からの繰越金」入力 ＆ 合算**:
  - 前サイクルで余ったお金を入力し、今サイクルの自由費に合算。
- **「食費」トラック欄の独立**:
  - 日々の食費を記録し、1日あたりの平均支出や累計実績をリアルタイム集計。
- **リストの給料日基準ソート**:
  - 収支予定リストを日付昇順で整然とソート。
- **ダークモード / ライトモード完全連動**:
  - カレンダーを含む全画面が美しくテーマ連動（Glassmorphism すりガラス調）。
- **データバックアップ ＆ 復元**:
  - 完全保存用JSONエクスポート、Excel用CSVエクスポート、JSONバックアップ復元、デモデータ投入。

## セットアップ手順

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```
ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。
